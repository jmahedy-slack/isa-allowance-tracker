# ISA Allowance Tracker

Ninety One client-facing tool for relationship managers: track how much of the **£20,000** UK ISA allowance has been used in tax year **2026/27** (6 Apr 2026 – 5 Apr 2027).

## Try it

Open `Homepage.html` in a browser (self-contained, no build step).

## Tests

```bash
npm test
```

Covers UK tax-year date boundaries and acceptance scenarios for allowance used, remaining, and over-limit warnings.
